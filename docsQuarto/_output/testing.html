4  Pruebas y Validación

4.1 Introducción

Este capítulo documenta las pruebas realizadas a la aplicación móvil del Sistema Fitness para validar su correcto funcionamiento, rendimiento y usabilidad. Se incluyen pruebas funcionales, de integración, de rendimiento y de usabilidad.

4.2 Metodología de Pruebas

4.2.1 Enfoque de Testing

Se aplicó una estrategia de pruebas multinivel:

  1. Pruebas Unitarias: Validación de funciones individuales
  2. Pruebas de Integración: Validación de comunicación entre capas
  3. Pruebas Funcionales: Validación de casos de uso completos
  4. Pruebas de Rendimiento: Medición de tiempos de respuesta
  5. Pruebas de Usabilidad: Evaluación de experiencia de usuario

4.2.2 Entorno de Pruebas

Dispositivos Utilizados: - Samsung Galaxy A54 (Android 13) - iPhone 12 (iOS 16) - Xiaomi Redmi Note 11 (Android 12) - Emulador Android Studio (Android 11)

Condiciones de Red: - WiFi estable (50 Mbps) - Datos móviles 4G - Conexión lenta simulada (3G)

Backend de Pruebas: - URL: http://192.168.1.3:8081 - Base de datos: PostgreSQL con datos de prueba - Servidor: Spring Boot en desarrollo
