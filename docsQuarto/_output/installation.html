1  Guía de Instalación

1.1 Requisitos Previos

1.1.1 Software Requerido

Para ejecutar y desarrollar la aplicación móvil, necesitas tener instalados los siguientes componentes:

1.1.1.1 Node.js y npm

  • Node.js versión 18.x o superior
  • npm versión 9.x o superior (incluido con Node.js)

Verificar instalación:

node --version
npm --version

1.1.1.2 Expo CLI

npm install -g expo-cli

1.1.1.3 Editor de Código

  • Visual Studio Code (recomendado)
  • Extensiones recomendadas:
    • ES7+ React/Redux/React-Native snippets
    • TypeScript
    • Prettier - Code formatter

1.1.2 Dispositivos para Pruebas

Puedes ejecutar la aplicación en:

1.1.2.1 Opción 1: Dispositivo Físico (Recomendado)

  • Smartphone Android o iOS
  • App Expo Go instalada:
    • Android - Google Play
    • iOS - App Store

1.1.2.2 Opción 2: Emulador

  • Android Studio con emulador Android configurado
  • Xcode con simulador iOS (solo macOS)

1.2 Instalación del Proyecto

1.2.1 1. Clonar el Repositorio

git clone https://github.com/tu-usuario/fitness-mobile-app.git
cd fitness-mobile-app

1.2.2 2. Instalar Dependencias

npm install

Esto instalará todas las dependencias definidas en package.json, incluyendo: - React Native - Expo SDK - Axios - TypeScript - Expo Router - Y todas las demás librerías del proyecto

1.2.3 3. Configurar Variables de Entorno

Edita el archivo src/core/api/endpoints.ts y configura la URL de tu backend:

export const API_BASE_URL = 'http://TU_IP:8081';

Importante: - Para dispositivos físicos, usa la IP local de tu computadora (ej: http://192.168.1.3:8081) - No uses localhost ya que el dispositivo móvil no puede resolverlo - Asegúrate de que el backend esté corriendo y accesible desde la red

1.2.4 4. Verificar Configuración

Revisa que el archivo app.json tenga la configuración correcta:

{
  "expo": {
    "name": "fitness-app",
    "slug": "fitness-app",
    "version": "1.0.0",
    "orientation": "portrait",
    "platforms": ["ios", "android"]
  }
}

1.3 Ejecución de la Aplicación

1.3.1 Modo Desarrollo

1.3.1.1 Iniciar el servidor de desarrollo:

npx expo start

Esto iniciará el servidor de desarrollo de Expo y mostrará un código QR en la terminal.

1.3.1.2 Opciones de ejecución:

  1. En dispositivo físico:
    • Abre la app Expo Go en tu smartphone
    • Escanea el código QR que aparece en la terminal
    • La app se cargará automáticamente
  2. En emulador Android:
   npx expo start --android
  1. En simulador iOS (solo macOS):
   npx expo start --ios
  1. En navegador web (funcionalidad limitada):
   npx expo start --web

1.3.2 Scripts Disponibles

El proyecto incluye los siguientes scripts en package.json:

# Iniciar en desarrollo
npm start

# Ejecutar en Android
npm run android

# Ejecutar en iOS
npm run ios

# Ejecutar en web
npm run web

# Verificar tipos TypeScript
npm run type-check

# Limpiar cache
npm run clean

1.4 Configuración del Backend

1.4.1 Requisitos del Backend

La aplicación móvil requiere que el backend esté corriendo y accesible. Asegúrate de:

  1. Backend en ejecución:
   # En el directorio del backend
   ./mvnw spring-boot:run

  1. Puerto correcto: El backend debe estar en el puerto 8081

  2. CORS habilitado: El backend debe permitir peticiones desde el cliente móvil

  3. Base de datos: PostgreSQL debe estar corriendo con los datos iniciales

1.4.2 Verificar Conectividad

Prueba que la API sea accesible desde tu red local:

# Desde tu computadora
curl http://localhost:8081/ejercicios/obtener

# Desde otro dispositivo en la misma red
curl http://192.168.1.3:8081/ejercicios/obtener

Si obtienes respuesta JSON, la configuración es correcta.

1.5 Solución de Problemas Comunes

1.5.1 Error: “Unable to resolve module”

Solución:

# Limpiar cache de npm y Expo
rm -rf node_modules
npm cache clean --force
npm install

# Limpiar cache de Expo
npx expo start -c

1.5.2 Error: “Network request failed”

Causa: La app no puede conectarse al backend.

Solución: 1. Verifica que el backend esté corriendo 2. Asegúrate de usar la IP correcta (no localhost) 3. Verifica que el firewall permita conexiones en el puerto 8081 4. Confirma que el dispositivo móvil esté en la misma red WiFi

1.5.3 Error: “Expo Go app crashes”

Solución: 1. Actualiza Expo Go a la última versión 2. Verifica compatibilidad de versiones en package.json:

   npx expo-doctor
  1. Reinicia el servidor de desarrollo

1.5.4 La app no se actualiza automáticamente

Solución: 1. Activa “Fast Refresh” en la app Expo Go 2. Reinicia el bundler:

   npx expo start --clear

1.5.5 Problemas con TypeScript

Solución:

# Verificar errores de tipos
npm run type-check

# Reinstalar tipos
npm install --save-dev @types/react @types/react-native

1.6 Compilación para Producción

1.6.1 Build para Android (APK)

# Instalar EAS CLI
npm install -g eas-cli

# Configurar proyecto
eas build:configure

# Crear build para Android
eas build --platform android --profile preview

1.6.2 Build para iOS (solo con cuenta de desarrollador Apple)

eas build --platform ios --profile preview

El proceso de build se realiza en servidores de Expo y puede tardar 10-20 minutos.

1.7 Verificación de Instalación Exitosa

Una vez completados todos los pasos, deberías poder:

✅ Iniciar la app con npx expo start
✅ Ver la pantalla de login en tu dispositivo
✅ Conectarte al backend correctamente
✅ Registrar un nuevo usuario
✅ Iniciar sesión con credenciales válidas
✅ Navegar entre las pantallas de la app

Si todos estos puntos funcionan, la instalación fue exitosa.
